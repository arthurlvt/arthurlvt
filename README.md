### Hi, I'm Arthur 👋

Computer Science student at **Avignon University (CERI)**, in Provence, France.
I like building tools that solve my own everyday problems, and making them run **100% locally**.

#### 🔭 What I'm working on

- **[Toolbox](https://github.com/arthurlvt/toolbox)**: an all-in-one offline toolbox for macOS (Swift, SwiftUI).
  PDF tools, a LaTeX editor, OCR, course organizer, grades & ECTS, calculators and local AI with Ollama.
  Open source under GPL-3.0, [latest release](https://github.com/arthurlvt/toolbox/releases/latest).
- **Annalyse**: turns any past exam (PDF, scan, photo) into a clean LaTeX document, filed in a searchable bank.
  Built into Toolbox; a standalone Python version is coming.
- **AI assistant for first-year CS students**: a RAG project (university CMI program) built on carefully
  cleaned-up course material.
